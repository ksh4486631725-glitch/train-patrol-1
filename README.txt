열차순회 기록 앱 - PWA 패키지 (v4: 캐시 문제 수정 + 이전/다음 구간 버튼)
======================================================

폴더 안 파일:
  index.html, bundle.js, manifest.json, service-worker.js,
  icon-192.png, icon-512.png   → 배포에 필요한 파일 (GitHub에 이 6개만 올리면 됨)
  app-source.jsx               → 참고용 원본 소스, 배포에는 불필요


1) 배포하기 - GitHub Pages
------------------------------------------------
  1. GitHub 저장소의 Code 탭 → Add file → Upload files
  2. index.html, bundle.js, manifest.json, service-worker.js,
     icon-192.png, icon-512.png 만 선택해서 업로드 (같은 이름은 자동 덮어쓰기)
  3. Commit changes → 1~2분 뒤 기존 주소 그대로 반영됩니다


2) 이번에 고친 것: "입구/출구가 안 보여요" 문제
------------------------------------------------
  코드 자체에는 문제가 없었는데(직접 눌러서 계속 확인함), 앱을 껐다 켜도
  브라우저가 예전에 저장해둔(캐시) 파일을 계속 보여주는 경우가 있었어요.
  이번에 캐싱 방식을 "일단 새 버전 있으면 새 걸로, 인터넷 안 되면 그때만
  저장해둔 걸로"로 바꿨습니다. 이제부터는 배포할 때마다 자동으로 최신
  버전이 반영됩니다.

  ※ 그래도 안 보이면: 홈 화면 아이콘을 길게 눌러 앱을 완전히 종료한 뒤
  다시 켜보세요 (브라우저 탭을 여러 개 띄워둔 상태면 갱신이 늦어질 수 있어요).


3) 이번에 추가한 것: 이전 구간 / 다음 구간 버튼
------------------------------------------------
  화면 위쪽 구간 선택 드롭다운 양옆에 ◀ ▶ 버튼이 생겼어요.
  가까운 구간으로 바로 넘어가고 싶을 때 드롭다운을 열 필요 없이
  한 번 탭으로 이동할 수 있습니다. 맨 처음/맨 마지막 구간에서는
  각각 ◀ 또는 ▶ 버튼이 비활성화됩니다.


4) 터널 입구/출구 (지난 업데이트에서 추가, 계속 유지)
------------------------------------------------
  순서: 100 → 🚇 정림1터널 [입구 → T1~T7 → 출구] → 101 ...
  입구/출구도 다른 번호와 똑같이 상선/하선, 이상 유형 기록 가능하고,
  복사/붙여넣기 시 "정림1터널 입구"처럼 정확히 왕복됩니다.


5) 여러 사람이 같이 보는 "서버 저장" (선택 사항)
------------------------------------------------
설정하지 않으면 지금처럼 내 폰에만 저장되고, 설정하면 모든 폰이
같은 기록을 실시간으로 같이 봅니다. 무료 Firebase를 사용합니다.

【대표 1명이 하는 일 - 한 번만】
  ① https://console.firebase.google.com 접속 (구글 계정 로그인)
  ② "프로젝트 추가" → 이름 아무거나 → 프로젝트 만들기
  ③ 왼쪽 메뉴 "빌드" → "Realtime Database" → 데이터베이스 만들기
     → 위치는 아무거나 → "테스트 모드로 시작" 선택 → 사용 설정
  ④ 톱니바퀴(프로젝트 설정) → "내 앱" → </> 웹 아이콘 → 앱 등록
  ⑤ 화면에 나오는 firebaseConfig = { ... } 의 { } 안쪽 내용을 통째로 복사

【각자 폰에서 하는 일 - 이것도 한 번만】
  1. 앱의 "구간 범위 / 유형 설정" 화면 맨 아래 "서버 동기화"에 그 값 붙여넣기
  2. "저장하고 연결" → "서버 연결됨" 뜨면 성공
  3. 이제 이전 기록도 자동으로 불러오고, 실시간으로 서로 공유됩니다
  4. 끄고 싶으면 "연결 끊기"


6) 사용법
------------------------------------------------
  - 구간 선택(또는 ◀▶ 버튼) → 번호 목록에서 이상 있는 번호 탭
    → 상선/하선별 유형 선택 → 저장
  - 주황 테두리: 이번 순회 기록 / 파란 점선: 이전 순회 기록(안 건드리면 유지됨)
  - 번호를 눌러서 "삭제"를 누르면 이전 기록이든 이번 기록이든 완전히 지워짐
  - 순회 종료 후 "텍스트로 복사" → 서버 동기화 안 쓰면 다음 순회 시작할 때
    붙여넣으면 이어서 표시됨 (서버 동기화 쓰면 이 과정 필요 없음)


7) 데이터 저장
------------------------------------------------
  - 서버 동기화를 껐다면: 설정값과 기록은 폰 브라우저 안에만 저장됩니다.
  - 서버 동기화를 켰다면: 모든 순회 기록이 Firebase 서버에 저장됩니다.
  - 어느 쪽이든 순회 종료 후에는 "텍스트로 복사"로 한 번 더 백업해두면 안전합니다.
