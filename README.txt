열차순회 기록 앱 - PWA 패키지 (v8: 서버 저장이 실제로 안 되던 진짜 원인 수정)
======================================================

폴더 안 파일:
  index.html, bundle.js, manifest.json, service-worker.js,
  icon-192.png, icon-512.png   → 배포에 필요한 파일 (GitHub에 이 6개만 올리면 됨)
  app-source.jsx               → 참고용 원본 소스, 배포에는 불필요


1) 배포하기 - GitHub Pages
------------------------------------------------
  1. GitHub 저장소의 Code 탭 → Add file → Upload files
  2. index.html, bundle.js, manifest.json, service-worker.js,
     icon-192.png, icon-512.png 만 선택해서 업로드 (같은 이름은 자동 덮어쓰기)
  3. Commit changes → 1~2분 뒤 기존 주소 그대로 반영됩니다


2) ★ 진짜 원인을 찾았어요: 기록이 서버에 저장되지 않던 문제
------------------------------------------------
  Firebase 서버는 데이터 이름(키)에 마침표(.), 샵(#), 달러($), 대괄호([, ])를
  쓸 수 없게 막아놓는데, 저희 앱이 내부적으로 번호를 구분할 때 "#" 기호를
  쓰고 있었어요 (예: "s04#83#상선"). 그래서 서버에 저장을 시도할 때마다
  Firebase가 그 저장을 거부하고 있었고, 화면에는 아무 에러도 안 뜨다 보니
  겉으로는 "저장된 것처럼" 보였지만 실제로는 한 건도 서버에 도착하지
  않고 있었던 거예요.

  이번에 "#" 기호를 서버로 보낼 때만 안전한 다른 기호로 바꿔서 저장하고,
  받아올 때 다시 되돌리도록 고쳤습니다. 실제로 가짜 서버를 만들어서
  "번호를 태그 → 서버에 정상 저장되는지 → 초기화 후 재시작해서 다시
  불러와지는지"까지 전 과정을 테스트해서 확인했어요.


3) 서버 동기화 유지 / 해제 버튼 (지난 업데이트, 계속 유지)
------------------------------------------------
  한 번 연결하면 앱을 껐다 켜도 유지됩니다. 순회 시작 화면과 설정
  화면 양쪽에 "동기화 해제" 버튼이 있어요.


4) 서버 상태 진단 표시 (지난 업데이트, 계속 유지)
------------------------------------------------
  순회 시작 화면에서 서버에 저장된 기록이 몇 건인지 바로 보여줍니다.
  "지금 다시 확인하기"로 언제든 재확인 가능.


5) 서버 동기화 설정 (지난 안내, 계속 유지)
------------------------------------------------
  ① https://console.firebase.google.com → 프로젝트 선택 → 프로젝트 설정
  ② "내 앱" → SDK 설정 및 구성에서 "CDN" 선택
  ③ firebaseConfig = { ... } 의 { } 안쪽을 복사 (형식 그대로 붙여넣어도 됨)
  ④ 앱의 "구간 범위 / 유형 설정" 화면 맨 아래 "서버 동기화"에 붙여넣기
  ⑤ "저장하고 연결" → "서버 연결됨" 확인


6) 사용법
------------------------------------------------
  - 구간 선택(또는 ◀▶ 버튼) → 번호 목록에서 이상 있는 번호 탭
    → 상선/하선별 유형 선택 → 저장
  - 주황 테두리: 이번 순회 기록 / 파란 점선: 이전 순회 기록(안 건드리면 유지됨)
  - 번호를 눌러서 "삭제"를 누르면 이전 기록이든 이번 기록이든 완전히 지워짐
  - 순회 종료 후 "텍스트로 복사" → 서버 동기화 안 쓰면 다음 순회 시작할 때
    붙여넣으면 이어서 표시됨 (서버 동기화 쓰면 이 과정 필요 없음)


7) 데이터 저장
------------------------------------------------
  - 서버 동기화를 껐다면: 설정값과 기록은 폰 브라우저 안에만 저장됩니다.
  - 서버 동기화를 켰다면: 모든 순회 기록이 Firebase 서버에 저장됩니다.
    (이번에 고친 덕분에 이제 실제로 저장됩니다.)
  - 어느 쪽이든 순회 종료 후에는 "텍스트로 복사"로 한 번 더 백업해두면 안전합니다.
