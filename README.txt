열차순회 기록 앱 - PWA 패키지 (v5: 서버 설정값 붙여넣기 오류 수정)
======================================================

폴더 안 파일:
  index.html, bundle.js, manifest.json, service-worker.js,
  icon-192.png, icon-512.png   → 배포에 필요한 파일 (GitHub에 이 6개만 올리면 됨)
  app-source.jsx               → 참고용 원본 소스, 배포에는 불필요


1) 배포하기 - GitHub Pages
------------------------------------------------
  1. GitHub 저장소의 Code 탭 → Add file → Upload files
  2. index.html, bundle.js, manifest.json, service-worker.js,
     icon-192.png, icon-512.png 만 선택해서 업로드 (같은 이름은 자동 덮어쓰기)
  3. Commit changes → 1~2분 뒤 기존 주소 그대로 반영됩니다


2) 이번에 고친 것: 서버 동기화 설정값 "형식이 잘못됨" 오류
------------------------------------------------
  Firebase 콘솔에서 복사되는 코드는

    apiKey: "...",
    authDomain: "...",

  처럼 키에 따옴표가 없는 형태라 원래 정확한 JSON 형식이 아니었어요.
  이제 이 형태를 그대로 붙여넣어도 인식하도록 고쳤습니다. 아래처럼
  "const firebaseConfig ="이 앞에 붙어있거나 끝에 세미콜론(;)이 있어도
  자동으로 정리해서 읽습니다.

    const firebaseConfig = {
      apiKey: "...",
      ...
    };

  그냥 Firebase 콘솔에서 나온 { } 부분을 통째로 복사해서 붙여넣으시면 됩니다.


3) 서버 동기화 설정 방법 (다시 정리)
------------------------------------------------
  ① https://console.firebase.google.com → 프로젝트 선택 → 톱니바퀴(프로젝트 설정)
  ② 아래로 스크롤 → "내 앱" → SDK 설정 및 구성에서 "CDN" 선택
  ③ 나오는 코드 중 firebaseConfig = { ... } 의 { } 안쪽을 복사
     (앞뒤에 다른 게 좀 딸려 들어와도 이제 앱이 알아서 정리하니 괜찮아요)
  ④ 앱의 "구간 범위 / 유형 설정" 화면 맨 아래 "서버 동기화"에 붙여넣기
  ⑤ "저장하고 연결" → "서버 연결됨" 뜨면 성공

  ※ "연결 실패"가 뜨면 형식 문제가 아니라 databaseURL이 실제 값과
    다르거나 Realtime Database가 아직 안 켜져 있을 가능성이 커요.
    그럴 땐 화면 캡처해서 보내주시면 원인 봐드릴게요.


4) 이전 구간 / 다음 구간 버튼 (지난 업데이트, 계속 유지)
------------------------------------------------
  화면 위쪽 구간 선택 드롭다운 양옆 ◀ ▶ 버튼으로 가까운 구간을 바로 이동.


5) 터널 입구/출구 (지난 업데이트, 계속 유지)
------------------------------------------------
  순서: 100 → 🚇 정림1터널 [입구 → T1~T7 → 출구] → 101 ...
  입구/출구도 다른 번호와 똑같이 기록 가능하고 복사/붙여넣기 시
  "정림1터널 입구"처럼 정확히 왕복됩니다.


6) 사용법
------------------------------------------------
  - 구간 선택(또는 ◀▶ 버튼) → 번호 목록에서 이상 있는 번호 탭
    → 상선/하선별 유형 선택 → 저장
  - 주황 테두리: 이번 순회 기록 / 파란 점선: 이전 순회 기록(안 건드리면 유지됨)
  - 번호를 눌러서 "삭제"를 누르면 이전 기록이든 이번 기록이든 완전히 지워짐
  - 순회 종료 후 "텍스트로 복사" → 서버 동기화 안 쓰면 다음 순회 시작할 때
    붙여넣으면 이어서 표시됨 (서버 동기화 쓰면 이 과정 필요 없음)


7) 데이터 저장
------------------------------------------------
  - 서버 동기화를 껐다면: 설정값과 기록은 폰 브라우저 안에만 저장됩니다.
  - 서버 동기화를 켰다면: 모든 순회 기록이 Firebase 서버에 저장됩니다.
  - 어느 쪽이든 순회 종료 후에는 "텍스트로 복사"로 한 번 더 백업해두면 안전합니다.
